# Pulsar 桌面管理工具 UI 详细设计规范（最终完整版）

## 一、UI整体设计总纲

### 1\.1 设计定位

企业级消息中间件运维桌面客户端，风格采用**极简中后台工业风**，兼顾高密度信息展示、运维操作效率、长时间护眼，实现 Windows/macOS/Linux 三端渲染样式零差异、交互逻辑完全统一。

### 1\.2 设计原则

- **效率优先**：高频操作一键触达，资源层级清晰，减少弹窗深度与操作路径

- **信息分层**：核心指标突出展示，辅助信息默认折叠收纳，避免信息过载

- **稳定兼容**：全面适配 1080P/2K/4K、高分屏系统缩放、小屏笔记本

- **双主题强制适配**：亮色/暗色/护眼三套主题无样式错乱、色差、文字模糊

- **无障碍兼容**：支持字体缩放、全键盘操作、系统高对比度模式

### 1\.3 全局基础设计变量

#### 1\.3\.1 尺寸栅格规范

- 基础栅格：以 2px 为最小单位、4px 为主步进。间距令牌 `--spacing-xs/sm/md/lg/xl/xxl` = 4/6/10/12/16/24px——其中 6 与 10 是为桌面密度保留的中间档，不是笔误

- 圆角等级：小 4px（输入框/按钮）、中 8px（卡片/弹窗）、大 12px（页面容器）

- 字体体系：中文系统黑体栈（PingFang SC / 微软雅黑），代码与英文 JetBrains Mono

- 字号梯度：11px（辅助，下限）/ 12px（说明）/ 13px（次要）/ 14px（正文）/ 15px（模块标题）/ 18px（页面标题）。另提供四档全局字号切换（小/中/大/特大），antd 组件文字下限 12px、DOM 文字下限 11px

- 行高规范：常规文本 1.4 倍，代码/表格文本 1.2 倍

- 最小点击区域：控件高度 ≥28px（桌面鼠标优先；触摸场景另设 44px 热区）

#### 1\.3\.2 全局色彩体系

##### 亮色主题（默认办公）

- 主色：\#1677FF（按钮、选中态、图表主线、高亮）

- 成功绿：\#00B42A（连接正常、TPS稳定、无积压、操作成功）

- 警告黄：\#FF7D00（少量积压、网络波动、配置待修改）

- 危险红：\#F53F3F（断开连接、大量积压、操作失败、高危操作）

- 中性灰：F2F3F5\(背景\)、E5E6EB\(分割线\)、4E5969\(次要文字 7.10:1\)、64707D\(三级文字 5.05:1\)、1D2129\(主文字\)

- 危险文字：\#CF1322（`--color-danger-text`；`--color-danger` 是给边框/图标/按钮底的，压到正文上不够亮）

- 类型强调：\#722ED1（`--color-accent`，Topic/分区等节点类型，不并进主色）

##### 暗色主题（夜间运维）

- 主色：\#4096FF

- 成功绿：\#00C42A

- 警告黄：\#FF9500

- 危险红：\#FF4D4F

- 背景层级：\#17171A\(全局\)、\#232327\(卡片\)、\#2E2E33\(浮层/输入框/表格行\)

- 分隔线：\#3D3D45（不能与浮层底色同值，否则弹窗、卡片、右键菜单都没有边框，只剩阴影撑轮廓）

- 文字层级：\#F5F5F7\(主文字\)、\#C9CDD4\(次要\)、\#8F9AA6\(三级\)；危险文字 \#FF7875；类型强调 \#9E5CF7

> **对比度红线**：正文与次要文字 ≥4.5:1，三级文字（行号、代码注释、占位符）≥4.5:1，图标与边框等非文字元素 ≥3:1。三套主题各自独立验算，不从亮色推断暗色。

#### 1\.3\.3 阴影层级规范

- 轻阴影（卡片、列表）：0 1px 4px rgba\(0,0,0,0\.06\)

- 弹窗浮层阴影：0 4px 16px rgba\(0,0,0,0\.12\)

- 暗色模式统一降低阴影透明度，避免界面厚重发黑

## 二、全局固定布局骨架

全站采用**固定四分区骨架**，路由切换仅刷新内容区，骨架常驻，视觉高度稳定，无全局重渲染抖动。

```Plain Text
┌─────────────────────────────────────────────────────┐
│ 顶部全局导航栏（固定高度44px）                        │
├─────────┬───────────────────────────────────────────┤
│         │                                           │
│ 左侧集群│ 中间标签页工作区（多Tab容器）                │
│ 资源树  │                                           │
│ 240px   │                                           │
│         │                                           │
└─────────┴───────────────────────────────────────────┘
```

### 2\.1 顶部全局导航栏（44px）

从左至右分为 Logo区、全局搜索、状态区、工具区、设置菜单五大区域，常驻置顶不滚动。

- Logo区：脉冲流线图标 \+ Pulsar Manager Desktop，点击返回首页

- 全局搜索：宽度 `clamp(200px, 26%, 520px)` 随窗口伸缩，支持 Ctrl/Cmd\+K 聚焦，模糊匹配集群/租户/Topic

- 状态区：集群连接概况（在线/总数，点进跨集群巡检汇总）

- 工具区：监控、拓扑、告警（带未恢复计数）、更多（函数/巡检/汇总/文档/通知）、快速压测、日志导出、主题切换

- 菜单区：配置中心、快捷键设置、插件市场、关于、更新检查

> **密度说明**：导航栏取 44px 而不是早期草案的 48px，页签栏取 30px 而不是 36px。桌面工具一屏要同时放表格、图表与资源树，纵向每 4px 都是有效行数。这两处是**有意为之的偏离**，不是实现没跟上规范；同理，导航类入口超过 6 个时必须收进「更多」，否则最小窗口 1000px 放不下。

### 2\.2 左侧资源树面板（240px，可折叠）

固定资源层级结构，支持右键操作、多选批量运维、状态实时标色。

层级结构：集群 → 租户 → 命名空间 → Topic/订阅/Schema → 监控/压测/隧道

节点展示在线状态、积压数字、负载标记，底部支持刷新、清空缓存、折叠树。

### 2\.3 中间多 Tab 工作区

- Tab 栏高度 30px，支持无限新开、中键关闭、Ctrl/Cmd\+W 关闭

- 相同资源仅激活已有 Tab，不重复创建

- 首页 Tab 固定不可关闭

- 内容区统一内边距 12px（`.page-shell`），卡片间距 12px（`.page-body` 用 10px）

- 全局统一加载（`StateBlock`）、空数据、异常三类占位状态

- 页面级栅格必须带断点：图表类 `xs={24} xl={12}`、统计卡 `xs={12} xl={6}`。固定宽度的弹窗内部不适用视口断点（弹窗宽度不随窗口变化），保持固定栅格

## 三、核心页面模块 UI 详细设计

### 3\.1 首页：集群总览（列表 \+ 拓扑双视图）

首页顶部新增**视图切换开关：列表视图 / 拓扑视图**，用户选择后状态本地持久化，下次打开自动记忆。

#### 3\.1\.1 列表视图（原有默认）

2列自适应卡片布局：集群列表、全局指标大盘、最近操作日志、后台任务面板。

#### 3\.1\.2 新增：集群拓扑视图（核心可视化能力）

基于 ECharts Graph 关系图实现，可视化展示 **Broker、Topic、Partition、订阅组** 四层拓扑与消息流向，用于排查负载不均、分区异常、网络断层问题。

##### （1）节点类型与配色规范

|节点类型|形态尺寸|亮色主题|暗色主题|展示信息|
|---|---|---|---|---|
|Broker|大圆 60px|\#1677FF|\#4096FF|IP、CPU/内存、分区承载数、收发速率|
|Topic|方形 44px|\#722ED1|\#9E5CF7|分区数、TPS、积压总量|
|Partition|菱形 30px|\#00B42A|\#00C42A|归属Broker、游标位置、副本状态|
|订阅组|五边形 26px|\#FF7D00|\#FF9500|积压条数、消费者数量|

##### （2）连线流向规则

- Broker → Partition：主色实线，代表物理归属

- Partition → Topic：浅灰细连线，聚合归属关系

- Topic → 订阅组：橙色箭头线，代表消费流向

- 异常预警：高负载、断连、大量积压节点外圈红色闪烁描边

##### （3）拓扑画布交互能力

- 画布操作：滚轮缩放、左键拖拽平移、右键重置、右下角鹰眼缩略图

- 悬浮Tooltip：展示节点完整运行指标

- 右键菜单：与资源树能力完全对齐（查看监控、清理积压、编辑配置）

- 筛选面板：支持按租户、负载阈值、积压状态过滤节点，匹配节点高亮、其余灰度

- 导出能力：一键导出拓扑PNG、CSV结构数据，用于故障复盘

##### （4）拓扑性能防卡顿策略

- 节点超80个自动聚合分组，点击展开细分

- 拖拽、缩放事件节流 50ms，避免高频重绘

- 分层懒加载：默认只加载 Broker/Topic，分区、订阅按需展开

- 切页/关Tab 立即销毁 ECharts 实例，杜绝内存泄漏

### 3\.2 集群连接配置弹窗

固定宽680px自适应高度，分三步式表单：基础信息、认证配置、高级配置。支持直连/SSH隧道/K8s端口转发三种网络模式，自动渲染对应表单。实时表单校验、在线探活检测、敏感配置加密存储。

### 3\.3 Topic 详情核心页面

顶部指标卡片 \+ 二级 Tab 体系：订阅管理、消息浏览器、Schema 管理、配置编辑、监控拓扑。

#### 3\.3\.1 新增：消息列表智能截断与展开体系（重点优化）

解决超长 JSON/Payload 导致列表行高错乱、滚动跳跃、UI 抖动问题。

##### （1）默认截断规则

- Key / Payload 字段默认只展示**前50个字符**，超长自动追加「\.\.\.」省略

- ≤50 字符完整展示，无多余按钮、无占位空白

- 用户可在设置中自定义截断阈值：30/50/100 字符

##### （2）三级展开交互方案

- **悬浮Tooltip速览**：Hover 省略区域弹出带语法高亮的滚动预览框，快速查看不改动页面布局

- **行内折叠展开**：点击「展开」在当前行内嵌代码编辑器，支持格式化、复制、下载；同一列表仅允许单行展开，自动收起旧行，杜绝页面无限拉长

- **弹窗全屏查看**：超大报文支持弹窗独立查看，支持检索、折叠、重发、导出文件

##### （3）防滚动跳跃稳定机制

- 截断态所有列表行高度统一，无布局偏移 CLS

- 虚拟滚动预计算展开行高度，滚动平滑无跳动

- 刷新列表自动恢复用户已展开行状态，不强制重置

- 复制操作永远复制**完整原始报文**，而非截断文本

### 3\.4 消息压测引擎、SSH隧道管理、Schema 管理、权限管理

保留原有左右分栏、模板复用、自动报告、批量运维、版本对比、权限审计等完整能力，主题、组件、交互规范全局统一。
