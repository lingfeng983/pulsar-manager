## 这一版改了什么

### 可读性：三套主题各修一处「真的看不见」

- 亮色次要文字 `#86909c` → `#4e5969`，对比度 3.24:1 → 7.10:1。它不是装饰：`.hint-text` 这类 12px 说明文字在界面上有七十多处（表格副标题、参数说明、统计补充行），此前整片偏浅。
- 代码编辑器的行号与 JSON 注释由 `#c9cdd4` 改为 `#64707d`：行号 1.59:1 → 5.05:1。此前在亮色主题下行号基本看不见。
- 暗色主题的分隔线原来与浮层底色同值（`#2e2e33`），弹窗、卡片、右键菜单等于没有边框；现为 `#3d3d45`。三级文字同步提到 `#8f9aa6`。
- 新增 `--color-danger-text`：`--color-danger` 是给边框、图标、按钮底的，压到正文上只有 3.71:1，错误提示文字改用更深一档（亮 5.57:1 / 暗 6.98:1）。搜索下拉里的 Topic 图标也改用主题强调色（暗色下此前仅 2.58:1）。

### 密度：字号不再靠「压小」换行数

- 「小」字号档的 antd 基准字号 10px → 12px，DOM 下限 10px → 11px。中文在 10px 已经糊了，那点密度是用读不清换来的。
- 控件高度与内边距的收紧改为独立于字号：选「小」照样更紧凑，只是文字不会再被压到看不清。

### 布局：最小窗口不再挤

- 顶栏从 9 个同级按钮改为「监控 / 拓扑 / 告警 / 更多 ▾ / 折叠」，函数、巡检、汇总、文档、通知收进「更多」。按钮区从约 536px 降到约 310px。
- 新增状态区：顶栏直接显示「N/M 在线」，三态色点，点进跨集群巡检汇总；窗口小于 1120px 时自动让位给工具区。
- 监控页统计卡与图表卡补断点：小于 1200px 时图表单列（此前最小窗口下每张图只有约 362px 宽）。配置中心、租户/命名空间详情同理。固定宽度的弹窗内保持原栅格——视口断点套进固定宽弹窗会把两列莫名拆开。

### 交互与无障碍

- 文档中心的目录、锚点与检索命中行全部改成真按钮：此前是不可聚焦的 `div`/`li`，键盘用户进这一页只能看不能操作。
- 资源树与文档目录的拖动把手支持聚焦后用左右方向键调宽。
- 主题新增「跟随系统」：按系统深浅色解析，系统切换时界面跟着换，首帧就是正确颜色（不会先白一下）。
- 支持系统「减少动态效果」：开了之后过渡与动画压到不可感知。
- 表格/列表页加载态改为骨架屏（首页、告警中心、巡检、巡检汇总、函数中心、插件市场、资源详情），状态切换带 `role="status"` / `role="alert"`，读屏能播报。
- 消息浏览器接入统一的页面骨架（此前这个最密的页面没有内容区内边距，内容贴着页签栏）。
- 关于弹窗的 ⚡ emoji 换成矢量图标（emoji 字形跟着系统字体走，三端不一，也无法跟随主题色）。

### 后台

- **Admin 并发上限可配置**（设置 → 刷新节奏，1~64，默认 8）：进程级并发闸门，启动时按设置落一次，改完立即生效。此前并发窗口写死在代码里，多集群扇出时要么打爆 broker、要么本地排队过久。
- **探活失败原因回传**：`cluster:checkStatus` 现在连同每个集群的失败原因一起返回，首页状态标签悬停即可看到「连不上：端口不通 / TLS 失败 / Token 无效」，刷新失败时也按集群列出明细，不再只弹一句笼统的失败。

### 文档

- 设计规范文档的数字改成实现值（顶栏 44px、页签栏 30px、内容区 12px、页面标题 18px），并写明密度取舍的理由——此前文档与代码全面对不上，等于自定标准被判违规。
- 新增 `docs/design/UI-UX-现状审计.md`：问题清单、对比度实测值、逐条修复记录与验收方式。
