## 这一版改了什么

这一版没有新功能，全部来自一次全量代码审核：把「会静默出错」和「会悄悄丢数据」的地方逐个补上。

### 凭据密钥失效不再无声无息

凭据密钥文件损坏时，后台会轮换出一把新密钥并继续启动——但旧密钥加密的内容就再也解不开了，已存集群的认证参数与通知渠道密钥全部失效。以前这件事只写在一个没人读的字段里，用户看到的只是「所有集群突然都连不上」。现在启动时会弹一条不会自动消失的提示，说清楚发生了什么、需要重新填什么。

### 消息详情可以复制、可以放大

双击消息打开详情后：右上角新增「复制」，一键取走整段正文（JSON/XML 都是格式化后的内容）；旁边是放大/还原按钮，右下角还能拖拽改宽高，编辑器跟着弹框一起伸缩，长报文不用再在小窗口里滚。另外修掉了消息浏览器作为 Topic 内嵌页签时多套一层容器、左右边距比「概览 / Schema / 订阅」宽一倍的错位；「消息列表 N 条」「筛选」按钮与「起始位置」等参数现在合并成一行，统计与筛选靠右对齐。

### 告警规则支持「不低于 / 不高于」

后台一直支持 `≥` 与 `≤` 两种比较，界面却只给了「高于 / 低于」两项——从别处导入或手工改过的规则在编辑时会被悄悄替换成「高于」，再保存就把阈值语义改掉了。现在四种比较符都能选、能正确回显，恢复通知的措辞也按方向区分（「回落到」/「恢复到」）。

### 出错不再当没发生

- 应用设置、插件列表读取失败时按默认值显示，以前是静默的，现在会明确提示「已按默认设置显示」。
- 快捷键配置导入以前无论如何都报成功，实际可能一条都没写进库；现在按真实结果反馈。
- 命名空间 / Topic 策略同步的「预览」与「执行」以前出错会卡在 loading 且没有任何提示，现在会落到错误态并说明原因。
- 消费配置里损坏的 JSON 以前被当成空值吞掉，现在会报错，不会让一条坏记录看起来「正常但没配置」。
- 配置中心整库导入、告警中心批量删事件都补了二次确认——这两个操作都不好撤销。

### 单位口径统一

字节类指标一律按 1024 换算，单位相应改成 KiB / MiB / GiB。以前同一个数在监控页标 KB、在告警规则里标 MB，且都按 1024 除，看的人没法判断到底是 1000 还是 1024 进制。这次前后端一起改，包括写进告警事件正文的那份文案。

### 稳定性与边界

- 生产消息的条数上限从「只挡 0」改成 1–1000，避免一个手滑的极大值直接把内存打爆。
- 端口设置拒绝超出 65535 的输入，不再静默截断成另一个端口。
- 消费会话的后台任务异常退出时会正确摘除注册，不再留下一个「看起来在跑、其实已经死了」的会话。
- 拓扑图的延迟 resize 会随组件卸载一起取消，不再对着已销毁的图表实例操作。
- 巡检里同步的数据库读取与解密搬到阻塞线程池，不再卡住异步运行时。

### 界面细节

- 状态类文字改用专门的深色语义色（成功绿、警告橙），浅色主题下对比度达到可读标准。
- 标签（Tag）的圆角与描边不再被 antd 运行时样式覆盖回去。
- 消息详情与代码编辑器的拖拽把手可以用 Tab 聚焦、方向键调整，并带完整的读屏描述。
- 右键菜单所有项都禁用时仍能聚焦、Esc 能关掉，且不再把按键冒泡给全局快捷键。

## 工程化

- 发版脚本：发行版创建后，只要上传附件或匿名回读校验失败，会自动删除这个半成品发行版再报错。以前留下的坏版本会让旧客户端一直看到「有新版本」却下载校验失败。
- 新增最小 CI：类型检查、ESLint、Prettier、两套自测、渲染层构建，以及 Rust 的格式检查与单元测试。
- 运行时依赖与构建依赖分开归类，锁文件与 `.npmrc` 切回官方 npm 源。
- 一键体验用的 `docker-compose.yml` 端口改为只绑 `127.0.0.1`：standalone 默认没有认证，不该暴露到局域网。
