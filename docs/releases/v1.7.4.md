## 这一版改了什么

这一版的大多数问题有一个共同点：界面看起来成功了，实际没做或做错了。每一条都先写了能复现问题的失败用例，再修。

### 托盘「退出」一次即可退出

收进托盘后右键「退出」，窗口反而重新弹出来，要再点一次才真正结束。原因是退出是异步的，期间页面加载完成、3 秒兜底、托盘唤回三条路径都可能把窗口重新显示出来。现在这三条路径都会先看「是否正在退出」，托盘退出时也会先把窗口藏起来。

### 消息收发

- **批量消息的 ID 与确认。** 同一批里的消息共用一个 ID（丢了 batch_index），确认又总是发往第一个分区：分区 topic 上的确认落不到正确的分区。现在 ID 带上批内序号，确认按消息所在分区发送。
- **「全部确认」不再是零确认。**
- **离开页面后才回来的启动结果**不再留下没人管的消费者/生产者会话。

### 告警与凭据

- **告警不再把取数失败当成 0。** 某个 broker 取不到指标时，告警这一轮报错，而不是按 0 判定「已恢复」或误报。
- **凭据加密的明文回退分支不再删掉唯一的密钥**，之前它会让所有已加密的凭据再也解不开。

### 通知渠道

- 带令牌的 Webhook 地址不再原样回显。
- 发送后只写渠道状态，不再用旧快照整行覆盖期间的编辑。
- 钉钉/飞书支持加签；HTTP 200 不再等于成功，按各家的业务返回码判定。

### 生产者

- **「出错即停」只停连续发送**，会话本身保留；模板错误总会停下，速率填 0 表示不限速，停止原因会显示在页面上。
- **逐条发送选项生效**：分区键（固定值或取自报文字段）、事件时间、延迟投递，单次发送和连续发送都支持。
- **内联 JSON Schema 逐条校验**：每条报文渲染后在后台按 schema 校验，不合格的计入失败列表，报错文案与编辑器里的一致；Broker Schema 模式会明确拒绝，而不是假装校验过。
- 发送统计不再出现 NaN。

### 在线更新与集群配置

- **在线更新真正静默安装。** 之前传的是 `/SILENT`（另一种安装器的参数），NSIS 只认区分大小写的 `/S`，结果是弹出安装向导。
- **连接测试的结果不再串到下一次打开的弹窗**；关闭弹窗后才建好的测试隧道/转发会当场断开，不再白占本地端口。

### 已知未覆盖

- 会话级的生产者选项（批量、压缩、发送超时、路由、分块、访问模式）在建会话时仍被忽略；`seed` 仍不支持。
- 按分区确认只有单元测试，还需要在真实集群上端到端复核。
