## 这一版改了什么

### 概览页消费者列表重新可见

Topic 详情页「概览」里的消费者表格一直显示「暂无消费者」：前端契约中的 `TopicStats.consumers` 是 Electron 时代由主进程归一化出来的平铺数组，迁到 Rust 后 `pm_core::TopicStats` 并没有这个字段，`parse_stats` 也没做平铺，所以即使 broker 报了订阅和消费者，界面也拿不到。这一版在 Rust 侧补上派生字段——把顶层订阅与各分区统计里的消费者合并，按订阅、名称与连接信息去重，并用订阅级 type 兜底消费者的类型列；监控页切到单个 topic 时的消费者计数也一并修好（原来读同一个缺失字段会直接抛错）。

### 消息浏览器

- **Properties 列直接显示内容**：不再只给一个「N 个属性」的标签，改成逐行铺出前 3 对 `key: value`；属性过多时显示「共 N 项 · 还有 M 项」，悬停可以看全部，不会被几十个属性把行高撑爆。
- **Data 列改为操作列**：正文不再占着表格宽度，换成「查看」「重投」两个按钮；双击任意一行直接打开原来的全屏查看弹窗。重投仍是把正文与属性装回发送测试面板，由用户确认后再发，不代点。
- **可折叠过滤**：默认整块隐藏，点消息列表上方的漏斗图标才展开。支持按 Producer 包含、Properties 键或值包含、发布时间范围三个条件筛选当前已收到的消息；只作用于本地列表，不影响会话接收，导出也按筛选结果走（所见即所得），并常驻显示「筛出 X / Y 条」。

### 导出统一选位置

以前各页面导出走浏览器的 Blob 下载，文件由 WebView2 静默写进默认下载目录，既选不了位置也不知道文件去了哪。现在新增后台 `file:saveText` 通道，所有导出统一弹系统「另存为」对话框：消息浏览器、消费者工作台、配置中心、快捷键配置、集群巡检、多集群巡检共 6 处；成功后回显完整路径，取消不算失败。日志导出原本就走系统对话框，保持不变。
