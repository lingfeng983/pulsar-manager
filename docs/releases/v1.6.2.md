## 这一版修了什么

- **更新通道迁到 GitHub**：应用内「设置 → 检查更新」改为读取本仓库（`lingfeng983/pulsar-manager`）的发行版，下载地址只信任 GitHub 域名；原先指向的 Gitee 分发仓已停用，因此升级到本版请直接用安装包覆盖安装一次，之后即可在应用内自动检查更新。
- **压测参数真正生效**：生产者数、消息大小、压缩、批量发送、同轮消费与取消标记都按界面设置执行（此前有参数被忽略）；压测、拓扑、Worker 的返回结构与前端契约对齐，跑完不再出现空白或 undefined。
- **Reader 与「偷看」恢复可用**：Reader 支持分区 Topic，`latest` 从末尾开始读；偷看改为短命订阅消费者（不再借 Reader 冒充），消费者名、确认与重投参数真正传给 broker。
- **推送与动态键名**：后台推给页面的事件结构统一为 camelCase；`subscriptions` / `properties` / `partitions` 这类动态键名与 `raw` 原文保持原样，不再被改写。
- **配置导入导出补全**：导出包含集群与快捷键；导入返回结构化结果（哪一项失败、为什么），集群表单不会把上一次的密码带进新表单。
- **若干页面级修复**：租户 / 集群详情缺 `name` 时的解析失败、topic stats 412 回退、metrics「最近 N 条」、手动确认窗口无界增长等。
- **前端稳定性**：测试连接的竞态（连点会串结果）、集群探活重复请求、更新弹窗卡死、连接测试失败后的状态回填。

## 实机验证

在 Pulsar 3.3.9 standalone 集群上跑通全链路：Admin、租户、命名空间、分区 Topic、订阅、策略、原生收发、Reader、偷看、拓扑、Worker、巡检、压测（2 生产者 × 200 条 × 256B，failed=0）；测试资源已清理。
